# `open`（営業時間）フィールド 記入ガイド

各店舗の `"open": ""` に営業時間を記入すると、アプリの**「営業中」フィルター**と
**営業中/時間外バッジ**が自動で有効になります（空のままなら何も表示されず、フィルター対象外）。

記入後は `python3 scripts/validate_open.py` で形式チェックしてから push してください。

## 書き方

| 書き方 | 意味 |
|--------|------|
| `11:00-23:00` | 毎日 11時〜23時 |
| `11:30-14:00,17:00-23:30` | 昼・夜の2部営業（`,` 区切り） |
| `月-金 11:00-23:00; 土 11:00-15:00; 日祝 休` | 曜日別（`;` 区切り） |
| `17:00-25:00` または `17:00-1:00` | 深夜営業（翌1時まで） |
| `月・水・金 10:00-18:00` | 飛び曜日 |
| `24時間` | 終日営業 |
| `11:00-23:00(L.O.22:30)` | 括弧内は自由記述（判定では無視される） |

## ルール

- **時刻は `時:分` 形式**（`11:00`。`11時` や `11:00頃` は不可）
- セクションは `;` で区切る。曜日指定のないセクションは**全曜日**に適用
- **後のセクションが前のセクションを上書き**する  
  例: `11:00-23:00; 日 休` → 全日11-23時、ただし日曜は休み
- どのセクションにも**記載のない曜日は定休日扱い**  
  例: `月-金 11:00-23:00` → 土日は時間外と判定される
- 閉店時刻ちょうどは「時間外」（23:00閉店なら 22:59 まで営業中）
- **「祝」は祝日判定非対応のため無視される**（`日祝 休` は日曜のみ判定）
- 全角数字・全角コロン・`〜` などの表記ゆれは自動で吸収される
- 形式が不正な場合はエラーにはならず、**原文がそのまま表示されるだけ**で
  営業中フィルターの対象外になる（validate_open.py で検出可能）

## 記入例

```json
{
  "id": "shop-2",
  "name": "大衆料理・居酒屋　御影郷　ふくじゅ",
  ...
  "open": "月-金 11:00-14:00,17:00-23:00; 土 17:00-23:00; 日祝 休",
  ...
}
```
